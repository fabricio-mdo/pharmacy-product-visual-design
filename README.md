# Pharmacy Product Visual Design

Projeto de criação visual para produtos de farmácia de manipulação utilizando ferramentas Adobe para design, branding e mockups 3D.

---

## Sobre o projeto

Projeto desenvolvido com foco na criação de imagens profissionais para produtos farmacêuticos e manipulados, utilizando composição visual, identidade de marca e mockups realistas.

O objetivo foi desenvolver apresentações modernas para produtos voltados ao mercado farmacêutico.

---

## Funcionalidades

- Criação de mockups 3D
- Desenvolvimento visual de embalagens
- Manipulação profissional de imagens
- Design de identidade visual
- Apresentação realista de produtos
- Composição para marketing digital
